# Plantillas GOEI

Las plantillas son herramientas de consistencia y no tienen autoridad científica. Completar una plantilla no aprueba su contenido.

- `Plantilla_documento_controlado.md`: cualquier artefacto versionado.
- `Plantilla_decision_cientifica.md`: expediente que el comité puede usar para registrar una decisión.
- `Plantilla_componente.md`: especificación técnica derivada de una decisión aprobada.
- `Plantilla_ficha_fuente.md`: control bibliográfico y uso de evidencia.
- `Plantilla_registro_cambio.md`: impacto y compatibilidad de modificaciones.
