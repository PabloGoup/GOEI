# Mantenimiento del estándar

Contenedor del plano T4 propuesto en D-005: cambios, líneas base, compatibilidad y vigilancia. Su alcance científico permanece provisional hasta aprobar la gobernanza.

La infraestructura técnica vigente comprende:

- registro de cambios;
- líneas base de alcance explícito;
- política de releases y compuertas;
- expedientes reproducibles de release;
- herramientas de manifiesto y comparación.

Esta infraestructura no promueve decisiones, componentes ni versiones científicas por sí misma.
