# Política Issue-Only — KPI Admissibility Method Baseline v0.1.0

Esta baseline es inmutable. Ningún archivo congelado se sobrescribirá.

Todo cambio requiere:

1. Issue formal con rama e impacto;
2. decisión científica del Comité cuando cambie método, criterio, estado o regla;
3. auditoría técnica;
4. ratificación competente;
5. nueva versión y nuevo manifiesto;
6. preservación íntegra de v0.1.0.

Esta baseline no evalúa candidatos, no aprueba KPI y no modifica `GOEI-BSL-KPI-C-0001` ni D-006.
